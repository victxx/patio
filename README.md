# Patio

Live audio and tiny video broadcast through Ethereum's mempool, sent as pending transactions on testnets.

**Listen at [patio.fm](https://patio.fm).** Listening needs no wallet.

## What's here

- [`transport/`](./transport): how it works on Hoodi and Polygon Amoy, with minimal code to read and write packets and the registry contract. MIT licensed.
- [`ethdenver-2024/`](./ethdenver-2024): the original project from ETHDenver 2024, kept as it was.
